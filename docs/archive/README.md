# docs/archive (イニシアチブ証跡)

規則の正本は [../governance/documentation_governance.md](../governance/documentation_governance.md) の「イニシアチブ証跡 (archive)」です。

## 命名

| 種類 | フォルダー | 中身 |
| --- | --- | --- |
| 実装イニシアチブ | `impl-<slug>/` | 三点セット (`modification.md` / `status.md` / `test-results.md`) |
| 改修イニシアチブ | `mod-<slug>/` | 同上 |
| 仕様リライトの旧正本 | `spec-<slug>/` (または簡潔な英文名) | 旧仕様一式の freeze。三点セットは不要 |
